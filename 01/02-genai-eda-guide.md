# 📘 Generative AI for Exploratory Data Analysis

---

## 🌍 Real-World Scenario

Meet **Ayaan** and **Zara**, two data scientists working for a humanitarian organization responding to a natural disaster.

They must analyze data from multiple sources:

- Satellite imagery  
- Social media posts  
- Field reports  

### The Challenge:
- Massive, unstructured datasets  
- Need for real-time insights  

### Their Approach:
Using Generative AI, they:

- Automate data processing  
- Summarize key insights  
- Generate visualizations  

➡️ Result: Faster decisions and better resource allocation
